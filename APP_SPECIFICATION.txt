1. מהות האפליקציה (Application Overview)
--------------------------------------------------------------------------------
SubTranslate AI היא מערכת Full-Stack מתקדמת לעיבוד וידאו ותרגום כתוביות מבוססת בינה
מלאכותית (AI Vision & OCR). 

המערכת פותרת את בעיית הסרטונים שבהם הכתוביות צרובות בגוף הווידאו עצמו (Hardcoded /
Burned-in Subtitles) בשפות זרות, ללא קובץ כתוביות נפרד. המערכת מחלצת את הטקסט המקורי,
מתרגמת אותו לעברית תקנית וטבעית, ומאפשרת להסתיר את הכתוביות המקוריות ולהציג במקומן
כתוביות מעוצבות בעברית (כולל ייצוא סרטון חדש או קובצי כתוביות).


2. רשימת תכונות ויכולות מרכזיות (Key Features)
--------------------------------------------------------------------------------
א. מנוע OCR ותרגום רב-מודאלי (Multimodal AI OCR & Localization):
   * דגימת פריימים מהירה ומותאמת של קובץ הווידאו לאורך ציר הזמן.
   * זיהוי טקסט מוטמע בכל שפה (ספרדית, אנגלית, צרפתית, גרמנית, ערבית ועוד).
   * תרגום אידיומטי וקולח לעברית מודרנית בהתאמה להקשר המשפט.
   * חישוב וסנכרון חותמות זמן (Timestamps) מדויקות לרמת אלפיות השנייה.
   * מנגנון Resiliency רב-שלבי הכולל Fallback אוטומטי במקרה של עומסים ברשת.

ב. מסיכת כיסוי חכמה לכתוביות המקור (Hardcoded Subtitle Cover-Mask):
   * שכבת כיסוי דינמית להסתרת הטקסט המקורי ומניעת כפילות ויזואלית.
   * שליטה מלאה במיקום (Bottom Offset), גובה הפס, רמת שקיפות, צבע ואפקט Blur.
   * כפתור "הצג מקור" להשוואה והצצה בכתובית המקורית בלחיצה ממושכת.

ג. עורך כתוביות אינטראקטיבי (Interactive Subtitle Editor):
   * עריכה חיה של טקסט המקור, התרגום לעברית וזמני התחלה/סיום.
   * אפשרות תרגום מחדש נקודתי של שורה בודדת בעזרת AI.
   * הזזת זמנים גורפת (Batch Time Shifting) להקדמה או עיכוב כל הכתוביות יחד.
   * ייבוא והעלאת קובצי כתוביות SRT חיצוניים ישירות לעורך.

ד. התאמה טיפוגרפית ועיצוב כתוביות:
   * מבחר גופנים עבריים: Heebo, Rubik, Assistant, Varela Round.
   * שליטה בגודל גופן, הדגשה, קו מתאר (Stroke), צבע ורקע תיבת הכתובית.

ה. מנוע ייצוא והורדה (Export Engine):
   * ייצוא קובצי כתוביות תקניים בפורמט SRT ו-VTT (קידוד UTF-8 מלא).
   * ייצוא סרטון וידאו מלא (Burn-in Video Render) הכולל את הכיסוי והכתוביות החדשות.

ו. נגן וידאו היברידי:
   * סרטוני הדגמה מובנים (60FPS Canvas Engine) ב-1080p לבדיקה מיידית.
   * נגן HTML5 ילידי מואץ חומרה לקובצי וידאו מקומיים (MP4, WebM, MOV).


3. טכנולוגיות, ספריות וכלים בשימוש (Tech Stack)
--------------------------------------------------------------------------------
צד לקוח (Frontend):
-------------------
* Framework: React 18 (Hooks, Refs, Imperative Handles)
* Language: TypeScript (Strict Type Safety)
* Bundler & Build Tool: Vite
* Styling: Tailwind CSS (תמיכה מלאה ב-RTL וב-Dark Theme)
* Icons: Lucide React
* Graphics & Video Processing: HTML5 Canvas 2D API, MediaStream Recording API

צד שרת (Backend):
-----------------
* Runtime: Node.js
* Framework: Express.js (REST API Routes & Static SPA Middleware)
* AI SDK: @google/genai (Google Gen AI TypeScript SDK הרשמי)
* Configuration: dotenv

מודלי בינה מלאכותית (AI Models):
----------------------------------
* מודל ראשי: gemini-3.7-flash (Vision Multimodal OCR & Hebrew Translation)
* מודלי גיבוי: gemini-flash-latest, gemini-3.1-flash-lite
* אכיפת פלט מובנה: Structured Outputs באמצעות JSON Schema


4. תהליך הפעולה מקצה לקצה (Workflow Pipeline)
--------------------------------------------------------------------------------
1. טעינה: המשתמש מעלה קובץ וידאו או בוחר סרטון הדגמה.
2. דגימה: המערכת דוגמת 16–18 פריימים נבחרים מהווידאו לתמונות JPEG קלות.
3. ניתוח AI: הפריימים נשלחים לשרת שמעביר אותם למודל Gemini Vision.
4. פענוח ותרגום: המודל מזהה את מיקום הטקסט, מחלץ את המילים, מתרגם לעברית ומסנכרן זמנים.
5. הצגה ועריכה: הכתוביות מוצגות על גבי סרגל הזמנים והעורך, כאשר שכבת הכיסוי מסתירה את המקור.
6. ייצוא: המשתמש מוריד קובץ SRT/VTT או מייצא סרטון וידאו מלא עם הכתוביות בעברית.
